# almeidatiago.github.io

Personal academic page of Tiago Almeida, published with GitHub Pages at https://almeidatiago.github.io.

The site is plain static HTML with no build step: `index.html` holds all content and styles, and `.nojekyll` tells GitHub Pages to serve the files as they are. To add a publication, copy one `<li class="pub">` block in `index.html`.
